# 🍺 Homebrew Colectivo

Official Homebrew Tap for **Sena's AI Colectivo** tools and applications.

## Quick Installation

```bash
# Add the tap
brew tap XavaATI/colectivo

# Install Limpia-Defensa
brew install limpia-defensa
```

## Available Formulas

| Formula | Description |
| :--- | :--- |
| **`limpia-defensa`** | ✊ Native macOS System Security, Heuristic Antivirus (Quetzal Core), and Storage Optimization Engine |

## Verification
```bash
# Verify environment health and code signatures
limpia-defensa doctor

# Launch native macOS GUI
limpia-defensa-gui
```
